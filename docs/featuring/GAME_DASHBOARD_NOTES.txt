=== GAME LOOP ===

Loan Generator:
  - Every 15 seconds
  - Generate random loan application
  - Add to pendingLoans array
  - Show notification

Repayment Simulator:
  - Every 10 seconds
  - Loop through activeLoans
  - Each loan:
    * Check default (random based on credit score)
    * If default: mark as defaulted, deduct balance
    * If not: add monthly payment, update paidAmount
    * If paidAmount >= total: mark as paid

=== STATE MANAGEMENT ===

Global (gameStore):
  - player, company, fintech
  - updateBalance, addTransaction, addNotification

Local (useState):
  - pendingLoans: Array<Loan> (pending approval)
  - activeLoans: Array<Loan> (active/paid/defaulted)

=== TIMINGS (For Testing) ===

Development:
  - Loan generator: 15 seconds
  - Repayment: 10 seconds

Production (recommended):
  - Loan generator: 5 minutes (300 seconds)
  - Repayment: 1 minute = 1 day, so 30 days = 30 minutes

Edit di game/page.tsx:
  setInterval(..., 15000) → Change 15000 untuk adjust timing

=== BALANCE FLOW ===

Initial: Rp 100,000,000

Approve Loan (Rp 10 juta):
  Balance: 100M → 90M (expense)

Repayment (Monthly Rp 983k):
  Balance: 90M → 90.983M (income)
  ... every month
  Final: 90M → 101.8M (profit 1.8M)

Default (Loss Rp 5 juta):
  Balance: 90M → 85M (expense/loss)

=== ERROR HANDLING ===

Error: "Cannot read property 'name' of null"
  → player/company/fintech tidak ada
  → Check apakah sudah initialize game (onboarding)
  → Early return: if (!player) return <Loading>

Error: "setInterval is not a function"
  → Check import: useEffect dari 'react'

Error: "Memory leak detected"
  → setInterval tidak di-cleanup
  → Add: return () => clearInterval(interval);
