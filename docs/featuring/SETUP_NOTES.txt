=== KEY CONCEPTS ===

TypeScript:
  - Type = Alias for primitive/union types
  - Interface = Object shape definition
  - ? = Optional property
  - as const = Readonly (cannot change)

Zustand:
  - Global state management
  - persist = Auto-save to localStorage
  - set() = Update state
  - get() = Read current state

Next.js:
  - @ alias = Project root (from tsconfig.json)
  - Import: '@/lib/types' instead of '../../../lib/types'

=== TROUBLESHOOTING ===
Error: "Cannot find module '@/lib/types'"
  → Check tsconfig.json has paths configured
  → Restart TS server in VSCode

Error: "crypto is not defined"
  → Use crypto.randomUUID() (available in browser)
  → For Node.js, use import { randomUUID } from 'crypto'

Error: "Zustand persist not working"
  → Check localStorage is enabled in browser
  → Check STORAGE_KEY is unique
  → Clear localStorage and retry
